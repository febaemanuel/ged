Bem-vindo ao Sistema GED

Este é um sistema de Gerenciamento Eletrônico de Documentos com integração de IA.

API REST

O sistema funciona principalmente através de uma API REST. Endpoints disponíveis:

  • Autenticação: /auth/login, /auth/register, /auth/me
  • Documentos: /documento/lista, /documento/criar, /documento/<id>
  • Tarefas: /tarefa/lista, /tarefa/criar, /tarefa/<id>/concluir
  • IA: /ia/extract/<id>, /ia/classify/<id>, /ia/search
  • Relatórios: /relatorio/pdf/tarefas_atrasadas, /relatorio/pdf/geral
  • Dashboard: /, /dashboard/stats

Funcionalidades

  • Gerenciamento completo de documentos (POPs, Manuais, Protocolos)
  • Fluxo de aprovação com tarefas
  • Integração com APIs de IA (extração, classificação, busca semântica)
  • Geração de relatórios em PDF
  • Controle de vencimento automático
  • Repositório público de documentos

Para começar

Use uma ferramenta como Postman ou cURL para interagir com a API:

# Login
curl -X POST http://localhost:5000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@example.com", "senha": "admin123"}'

# Listar documentos
curl -X GET http://localhost:5000/documento/lista \
  -H "Cookie: session=<session_cookie>"
